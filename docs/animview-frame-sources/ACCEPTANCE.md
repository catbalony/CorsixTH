# Native wxWidgets acceptance and maintainer-feedback gate

**Status: blocked/unverified at handoff.** Local tests compiled the real `AnimView/th.cpp` with **test-only substitutes** for wx file/image classes; they did not compile or run the dialog in `frmMain.cpp`.

## 1. Run the engine regressions

From the repository root, with Python 3 and a C++17 compiler:

```sh
bash AnimView/tests/frame_sources/run.sh
bash AnimView/tests/frame_sources/run.sh --sanitizers
```

Fixtures are generated to a temporary folder and contain only original synthetic art. Failed file loads must preserve the last valid data; a successfully replaced DAT must refresh decoded pixels. Malformed element lists must fail without returning misleading references.

## 2. Compile the actual optional AnimView GUI

On a machine with wxWidgets development headers and libraries, configure CorsixTH's CMake project with the optional AnimView target enabled (for example `-DBUILD_ANIMVIEW=ON`; consult the CMake files and platform's dependency instructions). Record exact OS, dependency versions, build command, compiler/linker output, revision and any errors. Do not alter normal game or Lua code to satisfy the test.

The original test environment did not contain wxWidgets, and couldn't reach package mirrors. An earlier isolated Ubuntu acceptance workflow was prepared in review artifacts but **was not run**, and has deliberately not been installed on this engineering branch as a new CI dependency.

## 3. Validate the real desktop interaction

Use legally acquired locally extracted original game data, or synthetic fixtures generated by:

```sh
python3 AnimView/tests/frame_sources/generate_fixtures.py /tmp/animview-frame-source-fixture
```

The GUI fixture is `/tmp/animview-frame-source-fixture/fixture` with `DATA` and `QDATA` directories. Open AnimView, select an animation and frame, open **Frame sources...**, select different element references and verify sprite ID, offsets, dimensions, layer/mask labels and correctly updated original indexed sprite preview. Check error handling, masked references, close-and-return frame position and playback preference. Test at 1280×800 and 1920×1080 using compact normal text size. Capture an **actual wxWidgets window screenshot** and check keyboard/mouse usability; never substitute a standalone C++ preview PNG.

## 4. Check practical developer value before proposing upstream

Ask a maintainer to compare unchanged AnimView and this prototype on a concrete graphics problem (e.g. overlays/positioning, rather than animation playback timing alone). Record whether the new trace workflow saves manual searching. Include a concise bug reproduction and user feedback in any eventual proposal. Building successfully is necessary, **not sufficient**, for a mainline merge.

No changes to `master`, no merge, no PR and no new features are required by this engineering checkpoint.
